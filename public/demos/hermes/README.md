# Öffentliche Hermes-Vitrine

Eigenständige Browser-Simulation mit erfundenen Aufgaben, Kontingenten und Messwerten. Kein Backend, kein Konto, kein produktiver Endpunkt. Die 3D-Aufnahmen zeigen synthetische Läufe des privaten Originalleitstands. Sein WebGL2-Motor und alle Produktmodule bleiben ausgeschlossen. Browsercode dieser bewusst ausgewählten Vitrine ist öffentlich lesbar.
