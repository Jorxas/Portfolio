# Öffentliche THOT-Vitrine

Bestehende getrennte Offline-Simulation mit fiktiven Konten, Kampagnen und Zeitpunkten. Keine Anmeldung, kein Plattformzugriff, keine Veröffentlichung. Enthalten sind ausschließlich statische Darstellung und vereinfachte Demoregeln; kein Produktbackend, keine Konfiguration oder Datenbank. Browsercode dieser bewusst ausgewählten Vitrine ist öffentlich lesbar.
